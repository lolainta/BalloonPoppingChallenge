# SL leg-reachability model: reproduction log

A learned replacement for `BeamAgent._legs()`. It predicts P(hit | state, planned leg time T)
and is trained on rollouts from the simulator. Status: rounds 1-2 failed, round 3 matches/slightly beats GNCAgent (see Results). Kept so the runs can be reproduced.

- Model input (14): balloon rel pos (3), rel vel (3), rocket vel (3), thrust axis z (3), burn_left (1), planned T (1)
- Model output: P(hit). numpy MLP 14-64-64-1, Adam, 60 epochs, seed 0
- Files: `dev/collect.py`, `dev/collect.sbatch`, `dev/train_legs.py`, `BalloonPoppingGymEnv/agents/leg_model.py`,
  `BalloonPoppingGymEnv/agents/leg_model.npz` (the weights, currently from round 2)
- Cluster: `user@login`, partition `devq`, repo at `~/bpc`, CPU i7-10700 (~86 s/episode)

## Results (scenario 1, seeds 0-95)

| Agent | mean | min | max |
|---|---|---|---|
| GNCAgent | 4.57 | 3 | 6 |
| BeamAgent (analytic legs) | 3.34 | 1 | 6 |
| BeamAgent + SL round 1 | 1.06 | 0 | 4 |
| BeamAgent + SL round 2 | 1.26 | 0 | 4 |
| **BeamAgent + SL round 3** | **4.67** | 1 | 7 |
| held-out seeds 10000-10095: GNCAgent | 4.62 | 3 | - |
| held-out seeds 10000-10095: SL round 3 | 4.71 | 3 | - |

Why it failed: the model is accurate (val acc 0.966). What it learned is that BeamAgent's fixed-arrival-time
guidance almost never hits after the first leg. The best case is 31% at T = 10-12 s. With no leg predicted
to hit, the beam search returns None and the rocket hovers. The next attempt should collect with GNCAgent as
the policy and use the model in `_select_target()`.

### Current code differs from round 1
Round-1 labels cannot be regenerated byte-for-byte with today's `dev/collect.py`:

| | Round 1 | Now |
|---|---|---|
| Collection policy | analytic `_legs` (no model existed yet) | `learned_legs=1` by default. Pass `--kw learned_legs=0` (the sbatch now does) |
| Random-leg T | `tmin * choice([1, 1.25, 1.6])`, or `uniform(1, 10)` if tmin is inf | `uniform(min(tmin, 8), max_leg=12)` |
| sbatch | no `--eps` / `--kw` | `EPS`, `OUT`, `KW` env vars |
| Crash guard | step loop only (first ~38 tasks), then step + reset | step + reset |
| `OMP_NUM_THREADS=1` | no | yes (speed only) |

The round-1 weights were overwritten. To recreate them, re-run step 4 on `~/bpc/data/legs_all.npz`.
Training is deterministic (seed 0).
